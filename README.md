# Chron *(Working Title)*

> ⚠️ **Working Title** – The game's title is subject to change during development.

An ancient fantasy monster-collecting RPG built with Unity.

## About

**Chron** is a solo-developed 2D RPG inspired by classic monster-collecting games, with a unique focus on exploration, hunting, and resurrection.

Instead of capturing creatures directly, players collect their remains and perform the **Rite of Binding** using **Soul Orbs** to create lifelong companions.

## Planned Features

- 🌍 Large handcrafted world
- ⚔️ Turn-based battles
- 🌿 Random encounters
- 🦴 Bone collection and resurrection
- 🔮 Rite of Binding
- 📖 Ancient encyclopedia *(working name: Chronicle)*
- 👹 150+ unique creatures *(initial goal)*
